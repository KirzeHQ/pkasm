# Contributing

All contributions are eagerly welcomed!  
We have very few requirements for contributing to make it as easy as possible for anyone to get involved.  

## Rules for contributing:

- All AI generated code must be properly checked and verified by a human before being submitted.
- Any PRs made must include an AI notice if you used AI to generate any part of the code.
- All contributions must be made under the same license as the project.

## How to contribute:

1. Fork the repository and optionally create a new branch for your changes.
2. Make your changes and ensure that they follow the project's coding standards and guidelines.
3. Test your changes thoroughly to ensure they work as expected and do not introduce any new issues.
4. Submit a pull request (PR) to the main repository with a clear description of your changes and the problem they solve. Include any relevant information, such as screenshots or code snippets.
5. Await feedback!

If you are asked to make changes to your PR, do not close it and recreate a new one. Instead push to the existing PR to make our lives easier.

## Issues

Please be concise and clear when reporting issues. Include as much relevant information as possible and any steps to reproduce errors.  
Also if you have any, then please include screenshots or code snippets to help us understand the issue better.

## Thanks!

Thanks for taking the time to contribute to PkASM! Your contributions are greatly appreciated and help make this project better for everyone.  
One gentle note, AI and human made contributions are both welcome, reviewed in the same way, and treated equally.
