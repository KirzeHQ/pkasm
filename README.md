# PkASM

## Overview

PkASM is a rust and assembly based cli. It focuses on tooling for Assembly programming and includes its own assembler, disassembler, and emulator. 
Designed to be lightweight and fast, while being easy to use.  
It is a work in progress and is not yet complete.
